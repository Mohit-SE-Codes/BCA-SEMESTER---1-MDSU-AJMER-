## ▶️ How to Run

### 1. Clone the repository

```bash
git clone <YOUR-REPOSITORY-URL>
```

### 2. Open the project directory

```bash
cd C-Projects
```

### 3. Compile a C program

```bash
gcc filename.c -o program
```

### 4. Run the program

**Windows:**

```bash
program.exe
```

**Linux/macOS:**

```bash
./program
```

> Make sure **GCC** or another C compiler is installed on your system.
